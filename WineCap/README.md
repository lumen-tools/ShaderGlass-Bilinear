### WinGlass/WineCap

This is an implementation of desktop/window capture using PipeWire/ScreenCast on Linux, that can be loaded
by WinGlass when running under Wine/Proton.

It's not a Windows .dll but a shared Linux library. It will be ignored when running on Windows.
